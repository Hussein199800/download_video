# تدفّق | Tadaffuq

مدير تنزيل عربي أصلي لأندرويد (9 فأحدث): يسرّع تنزيل الملفات العامة بتعدد الاتصالات، ويستأنفها بأمان، ويديرها في طابور ذكي — بلا إعلانات ولا متتبعات ولا تسجيل دخول.

> الحالة: **المرحلة الأولى (0.1.0)** — المحرك والتخزين والواجهات الأساسية والمتصفح. التورنت وFTP/SFTP والجدولة الزمنية وغيرها لم تُنفَّذ بعد (انظر الجدول أدناه).

## ما اكتمل واختُبر

| المجال | ما يعمل | كيف اختُبر |
|---|---|---|
| المحرك | حتى 32 اتصالاً، تقسيم ديناميكي لأكبر جزء متبقٍّ، ضبط تلقائي لعدد الاتصالات، كتابة مباشرة في مواضع الملف، إعادة استخدام الاتصالات | 14 اختبار تكامل مع خادم HTTP حقيقي (MockWebServer) + 15 اختبار منطق |
| الاستئناف الآمن | حفظ تقدم الأجزاء في Room بعد مزامنة القرص، رفض الاستئناف عند تغيّر الحجم/ETag/Last-Modified، If-Range على كل طلب جزء | إيقاف واستئناف دون إعادة تنزيل بايت واحد؛ تغيّر الملف قبل وأثناء التنزيل؛ «موت» العملية ثم الاستئناف |
| الأخطاء | إعادة محاولة تصاعدية مع عشوائية، Retry-After، الخوادم دون Range (اتصال واحد وبداية من الصفر)، الحجم المجهول، 403/404/410 | انقطاعات مقصودة في منتصف البث، أخطاء 500، خوادم دون Range ودون Content-Length |
| السلامة | فحص المساحة قبل الكتابة، لا كتابة فوق ملف موجود (اسم (1)…)، تحقق SHA-256/SHA-1/MD5 من بصمة مرجعية، تنبيه قبل فتح الملفات التنفيذية | اختبارات وحدة وتكامل |
| الطابور | أولويات، تنزيلات متزامنة، حد سرعة لكل مهمة وعام، إيقاف/استئناف/حذف جماعي، حزم | اختبارات تكامل للمدير الحقيقي مع Room |
| الشروط | Wi-Fi فقط (عام ولكل مهمة)، أثناء الشحن، البطارية المنخفضة، الحرارة (تقليل الاتصالات ثم الإيقاف)، حدود بيانات الجوال اليومية والشهرية، استئناف تلقائي عند عودة الشبكة | اختبارات منطق + تكامل (انقطاع ثم عودة الشبكة) |
| الخلفية | خدمة أمامية dataSync بإشعار موحد وزر «إيقاف الكل»، WorkManager للاستئناف بعد إعادة التشغيل وعودة الشبكة، معالجة حد Android 15 الزمني | بناء + lint؛ **لم يُختبر على جهاز حقيقي** |
| التقاط الروابط | المشاركة، «فتح باستخدام»، الحافظة (اختياري)، روابط متعددة، استيراد TXT/CSV، روابط متسلسلة `[001-120]`، مركز روابط | اختبارات منطق |
| المتصفح | تبويبات متعددة، خاص، مفضلة وسجل، بحث في الصفحة، وضع سطح المكتب، حجب النوافذ والمتتبعات (اختياري)، اعتراض التنزيلات مع الكوكيز وReferer، التقاط روابط الملفات العامة من الصفحة | بناء فقط |
| الملفات | تصنيف تلقائي، بحث عربي متسامح، فرز، تحديد جماعي، مشاركة، إعادة تسمية، بصمة، سلة 30 يوماً، المكرر/الكبير/الفارغ | لقطات واجهة |
| التقارير | استهلاك يومي/أسبوعي/شهري/سنوي (Wi-Fi والجوال) من البايتات الفعلية، نسبة النجاح، المساحة حسب النوع، CSV | لقطات واجهة |
| الواجهة | 5 تبويبات، عناوين كبيرة، بطاقات هادئة، Bottom Sheets، رسم حي للسرعة، خريطة أجزاء، مشهد حي، فاتح/داكن، عربي/إنجليزي، طبيب التحميل | 11 لقطة Robolectric (عربي/إنجليزي، فاتح/داكن) روجعت بالعين |
| أخرى | بلاطة إعدادات سريعة، اختصارات التطبيق | بناء فقط |

## لم يُنفَّذ بعد (المراحل التالية)
- التورنت/Magnet (المرشح: libtorrent4j)، FTP/FTPS/SFTP، Proxy من الواجهة (المحرك يدعمه)، المرايا واختيار الأسرع.
- الجدولة بالتاريخ والوقت وملفات التعريف (منزل/عمل/سفر)، والإجراءات بعد الاكتمال (فك الأرشيف، النقل).
- فك وإنشاء الأرشيفات، المجلد المشفّر بالبصمة، النسخ الاحتياطي والاستعادة، اختيار مجلد عبر SAF وUSB OTG.
- قسم المطورين (GitHub Releases، Hugging Face)، الاقتران مع إضافة متصفح، واجهة RPC.
- Widget، وتخصيص الألوان وترتيب التبويبات، ووضع الأجهزة اللوحية بعمودين.
- تشفير الكوكيز المحفوظة بـ Android Keystore (تُحفظ حالياً في قاعدة بيانات التطبيق الخاصة فقط).

## القيود التقنية المعروفة
- لا محاكي في بيئة التطوير (لا KVM): اختبارات Android تمت عبر Robolectric، لا على جهاز. **الخدمة الأمامية والإشعارات والمتصفح والأذونات تحتاج تجربة على هاتف.**
- نسخة release مصغّرة بـ R8 تُبنى بنجاح لكنها لم تُشغَّل؛ ملف APK المرفق نسخة debug.
- Android 12+ يمنع بدء خدمة أمامية من الخلفية؛ إن رفض النظام الاستئناف التلقائي يظهر إشعار «اضغط للاستئناف» بدل الادعاء بالعمل.
- التبويب الخاص لا يُسجَّل ولا يخزّن مؤقتاً، لكن الكوكيز مشتركة مع بقية التبويبات (قيد WebView).
- لا فحص فيروسات في التطبيق، ولا يُدّعى ذلك.

## البناء والاختبار
```bash
cd tadaffuq
./gradlew :engine:test                 # محرك التنزيل (29 اختباراً)
./gradlew :app:testDebugUnitTest       # المدير الحقيقي + المنطق + لقطات (21 اختباراً)
./gradlew :app:assembleDebug           # APK قابل للتثبيت
./gradlew :app:assembleRelease         # مصغّر؛ موقّع إن وُجد keystore.properties أو TADAFFUQ_KEYSTORE
```
يحتاج JDK 17+ وAndroid SDK 36 (`local.properties` → `sdk.dir`).

## البنية
```
engine/  Kotlin خالص: Prober, HttpDownloader, SegmentPlanner, RateLimiter, FileNames, Hashes, LinkTools, Doctor
data/    Room (tasks, segments, usage, packages, saved_links, bookmarks, history) + DataStore (Settings)
app/     DownloadManager (الطابور والشروط), DownloadService, ResumeWorker, واجهات Compose
```
الملفات في `التنزيلات/تدفق/<النوع>/`، وأثناء التنزيل باللاحقة `.tdq`.
