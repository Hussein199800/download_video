# جَنى — وثيقة التصميم

**التاريخ:** 2026-10-29 · **الحالة:** معتمد شفهياً، بانتظار مراجعة الوثيقة

## 1. الهدف
تطبيق أندرويد شخصي لتنزيل الفيديو والصوت من يوتيوب وفيسبوك وتيك توك وإنستغرام وأكثر من 1800 موقع يدعمها yt-dlp، بلا إعلانات ولا تحليلات. الأولوية **للاستمرارية الطويلة**: أن يبقى التطبيق يعمل سنوات دون إعادة بناء، وأن تسهل صيانته.

- **المستخدم:** صاحب المستودع ومعارفه (توزيع APK من GitHub Releases، لا متجر Google Play).
- **الصيانة:** يعتمد المالك على Claude بالكامل؛ لذلك الكود صغير وواضح ومغطى بالاختبارات.
- **المرجع:** أفكار مأخوذة من VRKA Android (GPL-3.0)، دون نسخ كوده. التصميم والإطار مأخوذان من تطبيقَي المالك «سكينة» و«طاقتي».

### معايير النجاح
1. لصق رابط أو مشاركته من تطبيق يوتيوب/تيك توك/… يبدأ التنزيل بثلاث نقرات على الأكثر.
2. قائمة تشغيل كاملة تُنزَّل دفعة واحدة بإعداد موحّد.
3. عند تغيّر موقع ما، يُصلَح التنزيل بزر «تحديث مكوّن التنزيل» دون إصدار جديد للتطبيق.
4. كل إصدار جديد يُثبَّت فوق القديم من داخل التطبيق.

### خارج النطاق (الآن)
المتصفح الاحتياطي GeckoView، تجاوز DRM أو تسجيل الدخول، النشر على المتاجر، دعم iOS.

## 2. الهوية والتصميم
- **الاسم:** جَنى (Jana) — ما يُجنى ويُقطف. الحزمة `com.jana.downloader`.
- **اللغة:** عربية بالكامل، RTL.
- **الثيم:** نهاري، ليلي، تلقائي. خلفية بتدرجات شعاعية خفيفة كطاقتي.
- **الألوان:** لا لون واحد؛ لكل نوع بطاقة تدرّجها الخاص:
  فيديو `c-sky`، صوت `c-violet`، قائمة تشغيل `c-amber`، السجل `c-green`، الأخطاء `c-pink`، الإعدادات `c-slate`. اللون الأساسي للأزرار نيلي (`--pri`).
- **البطاقات:** زوايا 22px، حدود رفيعة، ظل ناعم، blur خفيف، أيقونة ملونة في دائرة متدرجة + عنوان + سطر شرح.
- **الخط:** IBM Plex Sans Arabic مدمج في التطبيق (يعمل دون إنترنت).
- **الشرح:** كل إعداد تحته سطر يشرحه، وكل خطأ يأتي بسبب وحل.
- **التخصيص:** الثيم، حجم الخط، الجودة الافتراضية، الصيغة الافتراضية للصوت، مجلد الحفظ، عدد التنزيلات المتزامنة (1–3)، تسريع aria2c، التقاط الحافظة، تسمية الملفات.
- **حول التطبيق:** «تطوير: **حسين محمد علي الطويل**. اللهم اغفر له ولوالديه، واجعل هذا العمل صدقة جارية في ميزان حسناتهم.»

## 3. الشاشات (خمسة تبويبات)
1. **الرئيسية:** حقل الرابط مع زر لصق، اقتراح الرابط من الحافظة، بطاقات (فيديو، صوت، قائمة تشغيل)، بطاقة «آخر التنزيلات».
   - بعد إدخال الرابط: بطاقة معاينة (الصورة، العنوان، القناة، المدة) ثم اختيار:
     - فيديو: أفضل / 2160 / 1440 / 1080 / 720 / 480 / 360.
     - صوت: MP3 (128/192/320) أو M4A (بلا إعادة ترميز).
   - **صفحة قائمة التشغيل** (فرعية): عنوان القائمة وعدد المقاطع، قائمة بمربعات اختيار، «تحديد الكل/إلغاء الكل»، إعداد واحد للجميع، زر «أضف N إلى الطابور».
2. **التنزيلات:** الطابور الحالي: تقدم، سرعة، وقت متبقٍ، حالة. أزرار: إلغاء، إعادة المحاولة، مسح المكتمل.
3. **السجل:** بحث، فلترة حسب الموقع والنوع، فتح، مشاركة، حذف (من السجل فقط أو مع الملف).
4. **الشرح:** دليل مختصر لكل موقع، ماذا تفعل عند كل خطأ، ومعنى الصيغ والدقات.
5. **المزيد:** الإعدادات، مكوّن التنزيل (الإصدار الحالي + تحديث)، ملف cookies، سجل التشخيص، ما الجديد، التحقق من التحديثات، مشاركة التطبيق، حول التطبيق.

## 4. البنية التقنية
على نمط سكينة وطاقتي: **Capacitor 8** + واجهة HTML/CSS/JavaScript بلا إطار، مجمّعة بـ esbuild، وطبقة **Kotlin** لما لا تستطيعه الواجهة.

```
واجهة JS (src/)                     Kotlin (android/.../com/jana/downloader/)
─────────────────                   ───────────────────────────────────────
main.js   التبويبات والصفحات        JanaPlugin.kt     جسر Capacitor
queue.js  حالة الطابور في الواجهة  ─▶ MediaEngine.kt    تغليف youtubedl-android (info, download, update)
formats.js تحليل الصيغ واختيارها      DownloadWorker.kt WorkManager + إشعار تقدم
errors.js ترجمة الأخطاء + الحلول      JobStore.kt       الطابور والسجل (JSON في ملفات التطبيق)
store.js  الإعدادات (localStorage)    Updater.kt        تحديث التطبيق والتحقق من التوقيع
update.js التحقق من الإصدارات         ShareReceiver     استقبال الروابط من تطبيقات أخرى
native.js الجسر + محرك وهمي للمتصفح
```

- **المحرك:** مكتبة `youtubedl-android` (yt-dlp + Python + FFmpeg + aria2c). يُحدّث yt-dlp بـ `YoutubeDL.updateYoutubeDL()` يدوياً، وتلقائياً مرة أسبوعياً.
- **الطابور:** مصدر الحقيقة في Kotlin (`JobStore`) ليستمر والتطبيق مغلق؛ الواجهة تستقبل أحداث التقدم عبر `notifyListeners`.
- **الحفظ:** `Download/جنى/` (وللقوائم `Download/جنى/<اسم القائمة>/`) عبر MediaStore، دون صلاحية تخزين عامة على أندرويد 10+.
- **الأجهزة:** minSdk 24، target/compile 36، ملفات APK منفصلة لـ arm64-v8a وarmeabi-v7a.
- **الخصوصية:** لا تحليلات. الاتصالات: المواقع المطلوبة، GitHub للتحديثات، مستودع yt-dlp للتحديث.

## 5. سير البيانات
1. رابط (لصق / مشاركة / حافظة) → `getInfo(url)` يشغّل `yt-dlp -J --flat-playlist`.
2. فيديو واحد → بطاقة المعاينة → اختيار الصيغة → `enqueue(job)`.
3. قائمة تشغيل → صفحة القائمة → تحديد المقاطع → `enqueue([...jobs])` بإعداد موحد ومجلد باسم القائمة.
4. `DownloadWorker` ينفّذ حتى N مهام متزامنة، يبث `progress` (نسبة، سرعة، متبقٍ)، ثم ينقل الملف إلى MediaStore ويضيفه للسجل.

## 6. الأخطاء
| الحالة | ما يراه المستخدم | الإجراء |
|---|---|---|
| خاص / يحتاج تسجيل دخول | «هذا المحتوى يحتاج تسجيل دخول» | استيراد ملف cookies |
| فشل الاستخراج | «الموقع غيّر طريقة عمله» | تحديث مكوّن التنزيل ثم إعادة المحاولة |
| انقطاع الشبكة | «انقطع الاتصال» | إعادة محاولة تلقائية حتى 3 مرات |
| رابط غير مدعوم | «هذا الرابط غير مدعوم» | شرح الروابط المدعومة |
| مساحة غير كافية | «المساحة غير كافية» | تنبيه قبل البدء عند معرفة الحجم |
| غير معروف | «حدث خطأ غير متوقع» | نسخ سجل التشخيص |

سجل التشخيص يحذف الـ cookies ورموز الاستعلام الحساسة من الروابط.

## 7. التحديثات والنشر
- **تحديث التطبيق:** كطاقتي — فحص GitHub Releases تلقائياً كل 12 ساعة ويدوياً من «المزيد»؛ تنزيل APK والتحقق قبل التثبيت من اسم الحزمة، وأن الإصدار أحدث، وأن التوقيع مطابق.
- **CI:** GitHub Actions: اختبارات JS ← بناء ← اختبارات Kotlin ← APK موقّع إن وُجد السرّان `JANA_KEYSTORE_BASE64` و`JANA_KEYSTORE_PASSWORD` ← نشر إصدار عند الدمج في `main` مع `release-notes.md`.
- **الإصدار:** رقمه في `package.json` و`src/version.js` و`android/app/build.gradle`، واختبار يتأكد من تطابقها.

## 8. الاختبارات
- `npm test`: تحليل الصيغ، بناء أوامر yt-dlp، ترجمة الأخطاء، تطابق الإصدار، منطق اختيار مقاطع القائمة.
- `npm run test:e2e`: الواجهة في Chromium مع محرك وهمي (`native.js`).
- `npm run test:android`: اختبارات وحدة Kotlin لبناء الأوامر وتحليل التقدم وJobStore.
