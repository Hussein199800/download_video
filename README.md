# سَيْل 🌊

تطبيق أندرويد عربي (8 فما فوق) لتنزيل **الفيديو والصوت وقوائم التشغيل** من يوتيوب وفيسبوك وتيك توك وإنستغرام وإكس وأكثر من 1800 موقع، **بلا إعلانات ولا تتبع**. كل شيء يجري على الهاتف.

## المزايا
- **رابط واحد أو مشاركة**: الصق الرابط، أو اضغط «مشاركة» في يوتيوب أو تيك توك واختر «سَيْل»، فتظهر معاينة بالعنوان والصورة والمدة.
- **فيديو أو صوت**: الفيديو MP4 بدقة تختارها (أفضل، 4K، 1440p، 1080p، 720p، 480p، 360p)، والصوت MP3 (128 أو 192 أو 320) أو M4A الأصلي دون تحويل.
- **قوائم التشغيل**: تظهر كل المقاطع مع مربعات اختيار و«تحديد الكل»؛ المقاطع الخاصة أو المحذوفة معطلة. إعداد واحد للجميع، وتُحفظ في مجلد باسم القائمة.
- **مدير تنزيلات متكامل**: كم حُمّل ومن كم وكم بقي والسرعة والوقت، وإيقاف مؤقت واستكمال من حيث توقف، وترتيب الطابور، وأزرار في الإشعار، وتفاصيل كل تنزيل، ولصق عدة روابط دفعة واحدة.
- **طابور في الخلفية**: يستمر والتطبيق مغلق، وحتى 3 تنزيلات معاً، وإعادة المحاولة تلقائياً (30 ث، 2 د، 10 د)، والاستئناف وحده عند عودة الإنترنت.
- **الجدولة**: وقت محدد، و«على الواي فاي فقط»، ونافذة تنزيل يومية (مثلاً من 1 إلى 7 صباحاً).
- **سرعة**: أجزاء متوازية (2/4/8) وتقسيم يتجنب خنق يوتيوب؛ aria2c اختياري.
- **سيرفر 1 وسيرفر 2**: yt-dlp أولاً، وعند تعطله يتحدّث ثم ينتقل التنزيل وحده إلى NewPipe Extractor ليوتيوب وساوندكلاود وباندكامب وبيرتيوب. صفحة «المكوّنات» تعرض حالة كل جزء وقناة yt-dlp (مستقرة/Nightly).
- **حالات واتساب** وواتساب أعمال: عرض ما شاهدته وحفظه بضغطة.
- **السجل**: بحث وفلترة حسب الموقع والنوع، وفتح ومشاركة وحذف (من السجل فقط أو مع الملف).
- **أخطاء مفهومة**: كل خطأ بسببه وحله بالعربية مع زر الإجراء المناسب (تحديث المكوّن، استيراد cookies، إعادة المحاولة)، وسجل تشخيص يخفي البيانات الحساسة.
- **الشرح**: دليل مختصر داخل التطبيق لكل ما سبق.
- **التخصيص**: الثيم (تلقائي/نهاري/ليلي)، حجم الخط، الجودة والصيغة الافتراضيتان، عدد التنزيلات المتزامنة، التسريع، اقتراح الرابط المنسوخ.
- **الحفظ**: في `Download/سيل/` على الهاتف.

## التحديثات
- **مكوّن التنزيل (yt-dlp)**: المواقع تغيّر طريقة عملها باستمرار، فيتحدّث المكوّن **تلقائياً كل أسبوع** على الواي فاي، أو يدوياً من «المزيد ← مكوّن التنزيل»، دون حاجة لإصدار جديد من التطبيق.
- **التطبيق نفسه**: يتحقق من صفحة الإصدارات على GitHub كل 12 ساعة (أو يدوياً من «المزيد»)، فينزّل ملف المعالج المناسب لهاتفك ويتحقق قبل التثبيت أنه «سَيْل» نفسه، وأحدث، وموقّع بالمفتاح نفسه.

## إصدار جديد
1. ارفع الرقم في `package.json` و`src/version.js` (`VERSION` و`VERSION_CODE`) و`android/app/build.gradle` (`versionName` و`versionCode`). اختبار آلي يتأكد من تطابقها.
2. أضف الجديد في `src/changelog.js` واكتب ملاحظات الإصدار في `release-notes.md`.
3. ادمج في `main`؛ يبني GitHub Actions نسخة موقّعة وينشر الإصدار `vX.Y.Z` مع ملفين: `sayl-X.Y.Z-arm64-v8a.apk` (أغلب الهواتف) و`sayl-X.Y.Z-armeabi-v7a.apk` (الهواتف القديمة).

## مفتاح التوقيع (مرة واحدة فقط)
بدونه تُبنى نسخة تجريبية فقط ولا يُنشر إصدار. **احفظ الملف وكلمة المرور في مكان آمن؛ إن ضاعا لن تُثبَّت التحديثات فوق التطبيق القديم.**

1. على أي جهاز فيه Java، أنشئ المفتاح:
   ```bash
   keytool -genkeypair -v -keystore sayl.jks -alias sayl -keyalg RSA -keysize 4096 -validity 36500
   ```
2. حوّله إلى نص:
   ```bash
   base64 -w0 sayl.jks > sayl.jks.b64      # على ويندوز: certutil -encode sayl.jks sayl.jks.b64
   ```
3. في GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف:
   - `SAYL_KEYSTORE_BASE64`: محتوى `sayl.jks.b64`
   - `SAYL_KEYSTORE_PASSWORD`: كلمة المرور التي اخترتها
4. **لا ترفع `sayl.jks` إلى المستودع أبداً** (مستثنى في `.gitignore`).

## بناء APK على GitHub
مع كل رفع يبني GitHub التطبيق ويختبره. تجده في **Actions ← «بناء تطبيق أندرويد» ← آخر تشغيل ← Artifacts ← `sayl-apk`**.

## البنية التقنية
تطبيق **Capacitor 8**: الواجهة HTML/CSS/JavaScript بلا إطار عمل (esbuild)، وطبقة **Kotlin** للتنزيل نفسه.

| الطبقة | الملفات | الدور |
|---|---|---|
| المنطق | `src/links.js`, `src/formats.js`, `src/errors.js` | استخراج الرابط، بناء أوامر yt-dlp، تحليل المعلومات، ترجمة الأخطاء |
| الواجهة | `src/main.js`, `src/views/*`, `src/styles.css` | التبويبات الخمسة والصفحات الفرعية، RTL، نهاري/ليلي |
| الجسر | `src/native.js`, `src/state.js` | الاتصال بـ Kotlin، ومحرك وهمي للمتصفح والاختبارات |
| Kotlin | `android/app/src/main/java/com/sayl/downloader/` | `Engine` (yt-dlp) · `Server2` (NewPipe + HTTP + FFmpeg) · `ServerPolicy` متى نبدّل · `JobStore` الطابور والسجل · `DownloadWorker` التنزيل في الخلفية · `Failure`/`Retry` إعادة المحاولة · `Schedule` الجدولة · `StatusPlugin` حالات واتساب · `Saver` الحفظ · `ArgGuard` منع الخيارات الخطرة · `Updater` تحديث التطبيق |

- المحرّك: [youtubedl-android](https://github.com/yausername/youtubedl-android) الذي يضم yt-dlp وبايثون وFFmpeg وaria2c.
- الأفكار مستلهمة من [VRKA Android](https://github.com/MaverickRox/VRKA-Android) و[Seal](https://github.com/JunkFood02/Seal)، والتصميم على نمط «سكينة» و«طاقتي».
- **الخصوصية**: لا تحليلات ولا جهات خارجية. الاتصالات: المواقع التي تنزّل منها، وGitHub للتحديثات.

## الأوامر
```bash
npm install
npm test              # اختبارات المنطق (Node)
npm run test:e2e      # اختبارات الواجهة في Chromium مع محرك وهمي (الصور في tests/e2e/out)
npm run test:android  # اختبارات Kotlin
npm run serve         # الواجهة في المتصفح على http://localhost:8080 (محرك وهمي)
npm run apk           # نسخة تجريبية (يتطلب Android SDK)
npm run release       # نسخة موقّعة (يتطلب مفتاح التوقيع)
```
